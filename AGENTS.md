## Alcance autorizado
Esta entrega contiene exclusivamente agentes y documentación. No iniciar la aplicación
hasta que el usuario solicite la siguiente fase. Destinos acordados: backend/ para Node.js,
frontend/ para React y Tailwind; PostgreSQL como base de datos. No elegir silenciosamente
framework backend, ORM, proveedor de alojamiento o integración PAMM.
Los agentes aquí son perfiles de desarrollo, no agentes de inversión ni procesos autónomos
de la plataforma. No ejecutan operaciones financieras.

## Trabajo
Actúa sobre decisiones técnicas rutinarias dentro del encargo. Pregunta solo cuando una
respuesta afecte materialmente dinero, acceso, contratos o alcance y no conste ya.
No conviertas decisiones pendientes en valores por defecto. Continúa trabajo independiente.
No cargues todos los perfiles, historiales o skills por coincidencias superficiales.
Usa subagentes solo para trabajo delimitado que aporte valor; aplica el protocolo del router.
No deshagas cambios ajenos ni publiques secretos. Revisa el diff antes de commit/push.
El usuario autorizó guardar cambios en este repositorio; respeta permisos del entorno,
protecciones de ramas y alcance de cada tarea.

## Cierre
Verifica según riesgo y scripts existentes; no inventes comandos ni resultados.
Actualiza el requisito afectado y enlaza evidencia una sola vez. Registra los bugs
confirmados con prevención verificable. Distingue implementado, probado y publicado.
