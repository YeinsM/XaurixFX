# XaurixFX

Plataforma multicliente de seguimiento de inversiones agrupadas en una cuenta PAMM,
con cursos, análisis y enlaces a redes sociales.

Stack acordado: backend Node.js; frontend React + Tailwind; PostgreSQL.
El código futuro se separará en backend/ y frontend/. Aún no existe aplicación,
dependencias, migraciones, servicios ni despliegue.
